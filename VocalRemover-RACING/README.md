# VocalRemover-RACING

โปรแกรมแยกเสียงร้องและเครื่องดนตรีออกจากกันแบบอัตโนมัติ พัฒนาด้วยภาษา Python โดยใช้ระบบ AI ของ Demucs (htdemucs) มาพร้อมหน้าต่างโปรแกรมที่ใช้งานง่าย รองรองรับการลากไฟล์มาวางเพื่อประมวลผลทันที และสามารถเปิดการทำงานร่วมกับการ์ดจอ (NVIDIA CUDA) เพื่อช่วยให้แยกเสียงได้เร็วขึ้นครับ

## ฟีเจอร์หลักของโปรแกรม
* เลือกโหมดการแยกเสียงได้หลากหลาย ไม่ว่าจะเป็นแบบ 2 ชิ้น (เสียงร้อง + เสียงดนตรีรวม), 4 ชิ้น หรือ 6 ชิ้นดนตรี
* มีระบบตรวจจับและสลับไปใช้การ์ดจอช่วยประมวลผลให้โดยอัตโนมัติเมื่อตรวจพบระบบ CUDA
* สามารถลากไฟล์เสียงจากคอมพิวเตอร์มาวางในหน้าต่างโปรแกรมเพื่อต่อคิวทำงานได้ทันที
* มีแถบมอนิเตอร์แสดงการทำงานของ CPU, RAM และ VRAM แบบเรียลไทม์ขณะโปรแกรมกำลังทำงาน
* เลือกบันทึกไฟล์ผลลัพธ์ได้ทั้งฟอร์แมต WAV, MP3 (320kbps) และ FLAC

---

## วิธีติดตั้งและเริ่มใช้งาน

### สิ่งที่ต้องเตรียมในเครื่องคอมพิวเตอร์ก่อนรันโปรแกรม
1. ติดตั้ง Python เวอร์ชัน 3.10 ขึ้นไป
2. ติดตั้ง FFmpeg ในระบบคอมพิวเตอร์ของคุณ (จำเป็นมากสำหรับการประมวลผลและแปลงไฟล์เสียง)
3. ติดตั้ง NVIDIA Graphics Driver และ CUDA Toolkit (สำหรับคนที่ต้องการใช้การ์ดจอช่วยประมวลผล)

### ขั้นตอนการติดตั้งโค้ดสำหรับนักพัฒนา

1. ดาวน์โหลดโปรเจกต์นี้ลงเครื่องคอมพิวเตอร์ของคุณ
```bash
git clone https://github.com<ชื่อผู้ใช้-GitHub-ของคุณ>/VocalRemover-RACING.git
cd VocalRemover-RACING
```

2. สร้างและเปิดใช้งาน Virtual Environment
```bash
python -m venv venv
# สำหรับ Windows (PowerShell หรือ CMD):
.\venv\Scripts\activate
# สำหรับ Mac หรือ Linux:
source venv/bin/activate
```

3. ติดตั้งคลังไลบรารีที่จำเป็นให้ครบถ้วน
```bash
pip install -r requirements.txt
```

4. สั่งรันโปรแกรมเพื่อใช้งาน
```bash
python app.py
```

## โครงสร้างซอร์สโค้ดในโปรเจกต์
* app.py เป็นโค้ดหลักของโปรแกรม ทำหน้าที่จัดการหน้าต่าง GUI ทั้งหมดและสั่งงานระบบ AI Demucs
* .gitignore ไฟล์สำหรับข้ามการอัปโหลดพวกไฟล์ขยะ ไฟล์เสียงที่แยกออกมา และโมเดล AI ขนาดใหญ่ขึ้นไปยัง GitHub
* requirements.txt รายชื่อแพ็กเกจไลบรารีที่ใช้ในการรันโปรแกรม

## การร่วมพัฒนาต่อยอด (Contributing)

1. กด Fork โปรเจกต์นี้ออกไปยังบัญชี GitHub ของคุณ
2. สร้าง Branch ใหม่สำหรับฟีเจอร์ที่คุณต้องการเพิ่ม (เช่น git checkout -b feature/AmazingFeature)

4. Push โค้ดขึ้นไปบนคลังของคุณ (เช่น git push origin feature/AmazingFeature)
5. เปิด Pull Request กลับมาที่โปรเจกต์หลักเพื่อให้เราตรวจสอบโค้ดได้เลยครับ
